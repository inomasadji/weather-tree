## 1. Коды WMO (Open-Meteo `weather_code`)

`precip` — тип осадков, `int` — интенсивность 0…1, `cloud` — плотность облаков для слоёв.

| Код | Явление | precip | int | cloud | Ключевые визуальные признаки |
|----:|---------|--------|----:|------:|-------------------------------|
| 0 | Ясно | none | 0 | 0.00 | Чистое небо, резкие тени, максимальный контраст, солнце с гало |
| 1 | Преимущественно ясно | none | 0 | 0.15 | 1–2 мелких облака, тени почти резкие |
| 2 | Переменная облачность | none | 0 | 0.45 | Пятнистые облака, тени мягче, свет слегка приглушён |
| 3 | Пасмурно | none | 0 | 0.90 | Сплошной слой, тени размыты, палитра десатурирована |
| 45 | Туман | fog | 0.6 | 0.85 | Молочная дымка, дальний план исчезает, контраст −60 % |
| 48 | Туман с изморозью | fog | 0.7 | 0.85 | То же + белая кромка на ветках и траве, иней |
| 51/53/55 | Морось | drizzle | 0.2/0.4/0.6 | 0.8 | Мелкие редкие штрихи, тёмные точки на земле, мокрый ствол |
| 56/57 | Ледяная морось | drizzle (frozen) | 0.3/0.5 | 0.85 | Прозрачные «стеклянные» капли, наледь на ветках, скользкий блеск |
| 61/63/65 | Дождь | rain | 0.35/0.6/0.85 | 0.85 | Наклонные штрихи по ветру, рябь в лужах, тёмное небо |
| 66/67 | Ледяной дождь | rain (frozen) | 0.5/0.8 | 0.9 | Капли + наледь, ветки утолщаются блестящей коркой |
| 71/73/75 | Снег | snow | 0.3/0.6/0.9 | 0.85 | Хлопья, снег ложится на ветки и землю, приглушённый звук-свет |
| 77 | Снежная крупа | grains | 0.5 | 0.8 | Мелкие быстрые точки, почти горизонтальный снос |
| 80/81/82 | Ливневые дожди | rain | 0.5/0.7/0.95 | 0.75 | Короткие плотные струи, крупные капли, всплески, радуга при солнце |
| 85/86 | Снежные заряды | snow | 0.6/0.9 | 0.8 | Стена снега, резкие порывы, видимость падает |
| 95 | Гроза | rain | 0.7 | 0.95 | Тёмно-фиолетовая палитра, вспышки, подсветка силуэта, сильный ветер |
| 96/99 | Гроза с градом | rain + hail | 0.85 | 0.95 | Всё выше + град (белые штрихи под углом), скачущие отскоки |

**Правило фазового перехода:** если `temp ≤ +1.5 °C` и осадки не «ледяные», дождь
рендерится как снег. И наоборот: `temp ≥ +2 °C` и код снежный — снег переходит в мокрый.

## 2. Ветер

| Скорость | Порывы | swayAmp | Что видно |
|---------:|-------:|--------:|-----------|
| 0–8 км/ч | — | 0.03 | Лёгкая дрожь листвы, дым/туман стоит |
| 9–20 | — | 0.20 | Ветки качаются, листва шелестит, облака плывут |
| 21–35 | 40+ | 0.45 | Заметный наклон ствола, одиночные листья срывает |
| 36–55 | 60+ | 0.70 | Ствол гнётся, листопад усиливается, осадки под углом 20–30° |
| 56+ | 75+ | 0.95 | Сильный изгиб, ветки «хлыстом», снег/дождь почти горизонтально, возможен слом ветки |

Направление ветра задаёт: сторону наклона дерева, угол осадков, направление дрейфа
облаков и снежных заносов (сугроб с подветренной стороны).

## 4. Крона

| seasonPhase | Листва | Палитра | Детали |
|---|---|---|---|
| 0.00–0.12 | нет | — | Скелет, снег на ветвях, иней по утрам |
| 0.12–0.28 | нет | — | Почки-точки на концах веток, ствол самый тёмный |
| 0.28–0.42 | 25–60 % | `#7fb84a`, `#a8d46a` | Молодая светлая листва, цветение `#f3d6e4` |
| 0.42–0.68 | 95–100 % | `#2f6b32`, `#3f8a3d`, `#5aa84a` | Плотная крона, глубокая тень внутри |
| 0.68–0.82 | 95 % | `#4a8a3a`, `#7da43f` | Пожелтение по краям, пыльный оттенок |
| 0.82–0.94 | 90 → 40 % | `#c9a227`, `#d97a2b`, `#a83a2a` | Листопад, опад на земле |
| 0.94–1.00 | 0 % | — | Голые ветки, ковёр листвы, снег ложится |

## 5. Земля

| Состояние | Признак |
|---|---|
| `snowDepth` 0.0 | Трава/земля по сезону |
| 0.3 | Проплешины, снег в тени и у ствола |
| 0.7 | Сплошной покров, трава только пятнами |
| 1.0 | Сугробы, подветренный скос, снег на ветвях и «шапка» на кроне |
| `wetness` 0.5+ | Тёмная земля, лужи с отражением неба |
| `frost` 0.5+ | Белая кромка на траве, изморозь на ветках |
